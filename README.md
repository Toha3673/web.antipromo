# АнтиПромо

> Расширение для браузера, которое автоматически скрывает рекламные результаты с пометкой «промо» в поисковой выдаче Яндекса.

## Возможности

- 🚫 **Автоматическое удаление** рекламных блоков с пометкой «промо» / «promo» из результатов поиска Яндекса
- 🔄 **Динамическое отслеживание** — MutationObserver реагирует на подгрузку новых результатов и мгновенно их очищает
- 📊 **Статистика** — отслеживает количество скрытых рекламных блоков и проверенных страниц
- ⏹ **Включение / отключение** — расширение можно временно отключить через popup-меню
- 🌍 **Поддержка регионов** — работает на Яндекс.Ру, Яндекс.Беларусь, Яндекс.Казахстан, Яндекс.Украина и ya.ru

## Установка

### Из Chrome Web Store

*Скоро будет доступно*

### Вручную

1. Скачайте релиз:
``https://github.com/Toha3673/web.antipromo/releases``
2. Откройте **chrome://extensions** в браузере Chrome (или **edge://extensions** в Edge)
3. Нажмите **«Загрузить расширение»** (Load)
4. Выберите папку с проектом

## Как это работает

1. Расширение активируется на страницах Яндекса (`yandex.ru`, `ya.ru`, `yandex.com`, `yandex.by`, `yandex.kz`, `yandex.ua`)
2. [`content.js`](content.js) находит все элементы результатов поиска (`li.serp-item`, `div[data-cid]` и т.д.)
3. Для каждого элемента проверяется наличие текста «промо» или «promo» внутри
4. Если метка найдена - элемент удаляется из DOM, а счётчик заблокированных результатов увеличивается
5. MutationObserver отслеживает появление новых элементов (динамическая подгрузка) и повторяет проверку
6. Popup-окно ([`popup.html`](popup.html)) показывает статистику и позволяет включить/отключить расширение

## Технологии

- **Manifest V3** - современная спецификация расширений Chrome
- **Chrome Storage API** - хранение состояния и статистики
- **MutationObserver** - отслеживание изменений в DOM
- **Vanilla JS** - без внешних зависимостей
